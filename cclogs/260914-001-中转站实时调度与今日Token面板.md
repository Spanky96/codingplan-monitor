# 中转站实时调度 + 今日 Token 面板(管理员右侧栏)

日期:2026-09-14 ｜ 状态:已上线生产(8886),中转站双端点已部署,生产实测通过

## 需求

监控页新增管理员专属右侧栏,实时展示中转站(lwsub2api)全部用户:

1. **实时调度**:某用户当前占用几个调度、各是什么模型(如 yym 占 3 个:glm glm gpt),实时排行
2. **今日 Token 排行**:默认前 5,「更多」展开全部;榜单要并入 `/admin/external-resources` 外部资源用量(部分用户不走中转站)形成完整榜单

### 三轮迭代追加

- 初版:n/max 分数胶囊 + 模型文字徽章 → 改为**每调度一格色块** + 图例;折叠时左侧卡片区回收宽度
- 色块悬浮看不到详情(原生 title 被轮询重渲染打断);灰色"未知"块过多(窗口太短)
- 调度展示**真实上游模型**(glm-5.3 直连与 glm-5.3→glm-5.3-flash 转发异色);图例去悬浮
- **降压分流**:调度 15s 轮询,榜单 5 分钟 + 手动刷新;排行进度条改**按模型多色堆叠**

## 关键设计

- **数据链路**:中转站只读快照端点(内网开放 + 可选 token 门禁,仿 `/api/weight-snapshot` 先例)→
  监控后端代理缓存 → 前端轮询。不碰中转站管理 API,无凭证/2FA 依赖
- **调度数精确、模型近似**:占用数来自 Redis 槽位(`concurrency:user:{id}` ZCARD,仅存 requestID);
  模型用近 30 分钟完成请求的 `(model, upstream_model, count)` 聚合近似,不动并发热路径。
  块填充两遍:不同实际模型先各占一格(近期优先),再按完成次数补足 → 长流式不再出"未知"
- **颜色 = 实际调用模型**(upstream 优先):`activityEffectiveModel()`;全局色板(与 Token 曲线同源 8 色)
  按**模型名排序固定分配**,调度块/图例/堆叠条三处同模型同色,超出 8 种灰
- **悬浮用页面全局 `data-tooltip` 属性**(initBadgeTooltip 事件委托),勿用原生 title——轮询
  innerHTML 重建会打断原生 tooltip 计时器
- **折叠回收**:`.activity-panel.collapsed { width:auto; flex:0 0 auto }`,aside 收缩为竖把手宽,flex 自动让卡片区占满
- **外部资源合并**:`external_channels.owner_user_id` 归属用户,站内+外部 token/费用累加,
  `external_tokens` 单列;纯外部用户(不在活跃列表)以 email 兜底成行
